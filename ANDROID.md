# Ashen Meridian para Android — port nativo pendiente

El antiguo APK correspondia al runtime retirado y ya no es una salida
valida de este repositorio. No hay APK idTech jugable validado.

El destino sera Android NDK, integrando el codigo C++ de native/core con
el motor de DOOM 3 BFG y sus adaptaciones de EGL/OpenGL ES, entrada tactil,
audio, ciclo de vida Android, empaquetado y firma.

Antes se requiere una version Windows funcional y verificada.
